# Addon BeamNG.drive pour HubForge

51 actions avec les **raccourcis par défaut** de BeamNG.drive, rangées en 5 dossiers (Conduite, Feux, Réparer et véhicules, Caméras, Jeu), et deux pages prêtes à l'emploi :

| Page « BeamNG.drive » | | | | |
|---|---|---|---|---|
| Contact | Phares | Clignotant G | Warnings | Clignotant D |
| Frein à main | Klaxon | Rapport − | Rapport + | Mode boîte |
| Réparer | Recommencer | Caméra | Carte | Plus… |

La page « Plus… » : nitro, ESC/antipatinage, 4×4, gyrophares, pause, ralenti, mode photo, capture, masquer l'interface, caméra libre, téléporter, choisir un véhicule, circulation, sortir du véhicule.

La page s'affiche toute seule quand BeamNG.drive est au premier plan. Si tu as changé des raccourcis dans le jeu, modifie les touches correspondantes dans HubForge.
